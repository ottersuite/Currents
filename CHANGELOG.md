# Changelog

Notable user-facing changes to Currents are recorded here.

## [1.0.2](https://github.com/ottersuite/Currents/releases/tag/v1.0.2) — 2026-09-02

- Added inbox messages, user profiles, and community sidebar information.
- Added private in-app browsing with ephemeral tabs that do not share cookies or save browser history.
- Fixed completed videos so they can be replayed and scrubbed normally.
- Added AMOLED theming, app-wide text scaling, default sort controls, media-quality controls, and improved tablet layouts.
- Expanded account, feed, media, and adaptive-layout test coverage.

## [1.0.1](https://github.com/ottersuite/Currents/releases/tag/v1.0.1) — 2026-08-31

- Added a dedicated **NSFW content** settings screen.
- Added a persistent control for showing or hiding the side-menu **Random NSFW** shortcut.
- Unified the community drawer gesture so an inward swipe from anywhere along the right edge opens it.
- Removed the older centered gesture-exclusion strip.
- Kept spoilers covered independently from the automatic NSFW media setting.

## [1.0.0](https://github.com/ottersuite/Currents/releases/tag/v1.0.0) — 2026-08-31

- Published the first open-source Currents release and downloadable APK.
- Removed build-time Reddit credentials and made Client ID/User-Agent blank on first launch.
- Added user-editable Reddit installed-app OAuth configuration.
- Added gesture-first feeds, nested comments, native media, offline caching, filters, themes, and responsive phone/tablet layouts.
